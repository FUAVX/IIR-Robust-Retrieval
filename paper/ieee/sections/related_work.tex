\section{Related Work}
\subsection{Learned Global Representations}
Radenovi\'{c} \emph{et al.} use SfM reconstructions to obtain matching and non-matching training examples without manual retrieval labels, and introduce trainable GeM pooling~\cite{gem}. We adopt this descriptor-learning framework on a prepared subset, retaining a single global descriptor and disabling whitening and multi-scale inference.

Spatial attention is another way to alter feature aggregation. CBAM combines channel and spatial attention~\cite{cbam}. Our second run adapts its channel-mean and channel-max aggregation into a spatial gate with identity-preserving initialization and a scaled sigmoid.

Modern visual backbones broaden the representation choices. Vision Transformer (ViT) processes images as sequences of patches~\cite{vit}, while DINOv2 learns transferable visual features through large-scale self-supervision~\cite{dinov2}. They broaden the backbone and pretraining choices for retrieval. We focus on checkpoint selection and search processing within the VGG16--GeM descriptor family.

\subsection{Feedback, Geometry, and Ranking}
Visual query expansion uses initially retrieved images to refine the query. Chum \emph{et al.} combine feedback with spatial verification to limit false-positive expansion~\cite{totalrecall}. We evaluate descriptor-level averaging, similarity weighting, a cosine gate, and a geometry-filtered feedback pipeline. RootSIFT applies a normalization and square-root transformation to local SIFT descriptors~\cite{rootsift}; it supplies the local evidence in our re-ranking and verification stages. Homographies are estimated using RANSAC~\cite{ransac}.

Reciprocal rank fusion (RRF) combines rank positions rather than requiring matching score scales~\cite{rrf}. Diffusion can exploit neighborhood structure; Iscen \emph{et al.} study propagation over regional CNN representations~\cite{diffusion}. We study propagation on a graph built from one global descriptor per gallery image, examining how query-seed support changes the ranking.

DELG unifies learned local and global features in one network, combining GeM-based global retrieval with attentive local representations~\cite{delg}. SuperGlobal instead refines global representations for both retrieval and re-ranking~\cite{superglobal}. These two directions motivate our comparison of local verification with global-only feedback. RootSIFT--RANSAC and residual QE provide reference pipelines for measuring feedback gains alongside feature storage and query cost.

\subsection{Benchmark Protocols}
Oxford and Paris originate from landmark-retrieval research~\cite{oxford,paris}. Revised annotations and evaluation protocols were subsequently introduced~\cite{revisited}. We use the available \emph{legacy} ground truth with 55 queries per dataset. We extend these queries with deterministic corruptions to measure retrieval under controlled image degradation.
